**혼합곡(비브라토 사인파로 만든 보컬 대용 + 합성 피아노 반주, 100BPM)**
- 전체 음(선율+반주) 대비 원본: P/R/F1 = 0.83/1.00/0.91
- 혼합 모드 선율 추정: P/R/F1 = **0.63/0.83/0.71** (추정 16음, 정답 12음) → "실험적" 표시가 맞음

**10분 상한 부근 장시간 파일(595초 MP3, 무작위 멜로디 + 2박 베이스, 정답 1487음)**
- 처리 시간 33.2초 (디코딩 2.5 · 추론 25.1 · 후처리 0.3 · 악보 4.7), 최대 메모리 732MB
- 원본 P/R/F1 0.62/0.99/0.76 → 후처리 0.79/0.99/0.88
- 남은 오검출 387개의 분류: 지속 중인 베이스음이 멜로디가 시작될 때마다 다시 검출된 "재타격" 235개, onset 없음 113개, 동시 onset 배음(+16/+28) 39개
- 재타격은 진짜 반복 타건과 세기 비율 분포가 겹친다(진짜 0.91~1.09, 가짜 0.65~0.90). 실제 연주의 약한 반복음을 지울 위험이 있어 **보정 규칙을 넣지 않고 알려진 한계로 남겼다**.
- 600.5초 파일은 "분석 구간이 너무 깁니다" 오류로 정상 거부됨

### 측정에서 나온 개선 사항
1. **배음 유령음 제거 추가**: Basic Pitch 원본은 2·4·5배음 위치(+12/+24/+28반음)에 약한 음을 추가로 검출했다(정밀도 0.64~0.70). 동시 시작 + 배음 간격 + 세기 60% 미만 조건으로 제거하자 합성 사례 F1이 1.00이 되었다. 휴리스틱이라 UI에서 끌 수 있다.
2. **자동 BPM 접기**: 처음에는 60(정답 120), 215(정답 100)처럼 절반/두 배 오류가 났다. 70~160 범위로 접은 뒤 120.19 / 107.67이 되었다. 그래도 오차가 있으므로 UI에 "BPM 직접 입력 권장" 경고를 표시한다.
3. **악보 표기**: 불필요한 제자리표(♮), 제목 중복 표시, 점음표+16분쉼표 리듬을 고쳤다(조표에 맞춘 음이름, 레가토 보정).
4. **CLI stdout 오염**: basic_pitch가 stdout에 진행 메시지를 출력해 JSON이 깨지던 문제를 수정했다.
5. **SIGTERM 시 임시 폴더 잔존**: lifespan 종료 정리와 시작 시 고아 폴더 청소를 추가했다.

## 4. 검증하지 않은 것 (미검증)
- **실제 피아노 녹음**(어쿠스틱/디지털 피아노, 페달·잔향 포함): 시험하지 않았다. 합성 음원 결과(F1 1.00)는 실제 녹음 정확도를 보장하지 않는다.
- **실제 찬양/가요 음원**(보컬+밴드 혼합): 시험하지 않았다. 혼합곡은 합성 대용 음원으로만 측정했다(선율 F1 0.71).
- **Windows 실행**: `setup_windows.bat`/`run_windows.bat`은 작성만 했고 Windows에서 실행하지 않았다. 사용한 패키지(onnxruntime, numba 등)는 Windows용 Python 3.11 wheel을 배포하지만, 실제 설치는 확인하지 않았다.
- **macOS 실행**: 시험하지 않았다.
- **MuseScore PDF 생성 경로**: MuseScore가 설치되어 있지 않아 실제 호출을 시험하지 않았다(설치되지 않은 경우의 안내 경로만 테스트함).
- **Python 3.12/3.13**: 지원 범위 밖이라 시험하지 않았다.
- **동시 다중 사용자, 50MB에 가까운 고음질 파일**: 장시간 테스트는 12MB MP3로만 했다.
- **Klang·Lunaverus 사이트 동작 비교**: 도메인이 차단되어 관찰하지 못했다.
